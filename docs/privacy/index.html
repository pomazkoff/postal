Русский

Эта страница описывает только iOS-игру «Тишина. Последний почтальон», идентификатор games.mazkof.postman. На экране «Домой» приложение может называться «Почтальон». Разработчик — Илья Помазков / Mazkof Games.

Коротко

Это шагомер-путешествие: реальные шаги двигают почтальона по дороге. Аккаунт не нужен. Рекламы нет. SDK аналитики и рекламы в игре нет, рекламный идентификатор не читается. Прогресс и сохранения остаются на устройстве.

Наружу уходит только необязательный запрос погоды. Если разрешить геолокацию, игра берёт примерные координаты, округляет их и спрашивает у Open-Meteo код погоды, чтобы в мире было ясно, дождь, снег или туман. Если геолокацию не давать, погода выбирается по сезону, и координаты никуда не отправляются.

Шаги: HealthKit и движение

Игра читает количество шагов через HealthKit (приложение «Здоровье»), тип stepCount, только чтение. Шаги — это данные о движении, которые устройство уже записывает само. Отдельного SDK движения нет, в «Здоровье» игра ничего не пишет: список данных для записи пустой.

Сумма шагов с момента начала игры двигает героя и открывает сюжет. Число шагов не отправляется разработчику и не отправляется в Open-Meteo. На устройстве сохраняются дата старта и игровой прогресс, а не лента записей HealthKit.

Если доступ к шагам не дан, запросы возвращают ноль: почтальон не идёт от реальной ходьбы. iOS может будить игру в фоне (фоновая доставка HealthKit и фоновое обновление), чтобы пересчитать шаги и показать локальное уведомление о событии сюжета. Это по-прежнему обработка на устройстве.

Геолокация и погода

Геолокация необязательна. Игра запрашивает доступ «при использовании» и пониженную точность (kCLLocationAccuracyReduced). Непрерывного слежения нет: место спрашивается только чтобы обновить погоду.

Перед запросом широта и долгота округляются до двух знаков после запятой. Координаты на устройстве не сохраняются. Уходит только такой запрос, без ключа и без имени:

https://api.open-meteo.com/v1/forecast?latitude=…&longitude=…&current=weather_code

Ответ — числовой код погоды. Игра переводит его в одно из четырёх состояний: ясно, дождь, снег, туман. На устройстве кэшируются этот код и время запроса, не координаты. Новое место спрашивается примерно раз в час; сохранённый код может использоваться около трёх часов.

Если доступ запрещён, геолокация недоступна или сеть не ответила, запрос в Open-Meteo не отправляется. Тогда погода на день берётся по сезону: зимой чаще снег, осенью дождь и туман, летом чаще ясно.

Open-Meteo — сторонний сервис (open-meteo.com). Вместе с округлёнными координатами он, как любой сайт по HTTPS, может увидеть IP-адрес устройства. Почта, имя и шаги ему не передаются.

Что остаётся на устройстве

  • UserDefaults: пройден ли первый запуск, дата старта, показанный прогресс в шагах, режим источника шагов, код погоды и время кэша.
  • Файлы в Application Support (chapterN_state.json): сюжет — письма, выборы, журнал, флаги главы.
  • Локальные уведомления iOS о событиях сюжета. Они создаются на устройстве. Своего сервера push-уведомлений нет.

Игра не просит имя, почту и телефон. Нет кросс-приложенческого трекинга.

Чего нет

Нет продажи данных, нет рекламы, нет аккаунтов, нет SDK аналитики. Данные о шагах разработчику не передаются. В HealthKit ничего не записывается.

Как удалить данные

Удаление игры стирает локальные сохранения и кэш погоды. Записи шагов в «Здоровье» остаются: их ведёт система, не игра. Доступ к шагам и к геолокации отзывается в «Настройках» iOS, в разделах «Здоровье» и «Конфиденциальность и безопасность». Сброс истории в игре очищает сюжетный прогресс на устройстве.

Дети

Игра не предлагает регистрацию и не собирает имя или контакт через свой интерфейс.

English

This page covers only the iOS game «Тишина. Последний почтальон», bundle ID games.mazkof.postman. On the Home Screen the app may be labeled «Почтальон». The developer is Илья Помазков (Ilya Pomazkov) / Mazkof Games.

Summary

It is a walking game: your real steps move the postman along the road. There is no account. There are no ads. The game includes no analytics SDK and no advertising SDK, and it does not read an advertising identifier. Progress and saves stay on the device.

The only data that leaves the device is an optional weather request. If you allow location, the game takes an approximate position, rounds it, and asks Open-Meteo for a weather code so the world can be clear, rain, snow, or fog. If you deny location, weather follows the season and no coordinates are sent.

Steps: HealthKit and motion

The game reads your step count through HealthKit (the Health app), type stepCount, read-only. Steps are motion and fitness data the device already records. There is no separate motion SDK. The game writes nothing to Health: the share list in the authorization request is empty.

The step total since you started the game moves the character and advances the story. Step counts are not sent to the developer and are not sent to Open-Meteo. The device stores the start date and in-game progress, not the HealthKit sample log.

If step access is not granted, queries return zero and the postman does not advance from real walking. iOS may wake the app in the background (HealthKit background delivery and background refresh) to update the step total and post a local notification about a story beat. That processing stays on the device.

Location and weather

Location is optional. The game requests When In Use access and reduced accuracy (kCLLocationAccuracyReduced). It does not track continuously. It asks for a location only to refresh the weather.

Before the request, latitude and longitude are rounded to two decimal places. Coordinates are not stored on the device. The only request, with no API key and no name, is:

https://api.open-meteo.com/v1/forecast?latitude=…&longitude=…&current=weather_code

The response is a numeric weather code. The game maps it to one of four states: clear (ясно), rain (дождь), snow (снег), or fog (туман). The device caches that code and the time of the request, not the coordinates. A new location is requested about once an hour; the saved code can be used for about three hours.

If access is denied, location is unavailable, or the network does not answer, no request is sent to Open-Meteo. Weather for the day then follows the season: snow is more common in winter, rain and fog in autumn, clear skies in summer.

Open-Meteo is a third party (open-meteo.com). Along with the rounded coordinates, it can see the device IP address, as with any HTTPS request. Email, name, and step counts are not sent to it.

What stays on the device

  • UserDefaults: whether onboarding is done, the start date, displayed step progress, the step-source mode, the weather code, and the cache time.
  • Files in Application Support (chapterN_state.json): story progress — letters, choices, the journal, chapter flags.
  • Local iOS notifications for story events. They are created on the device. The game has no push-notification server.

The game does not ask for your name, email, or phone number. It does not track you across apps.

What the game does not do

It does not sell data, show ads, or offer accounts, and it does not include an analytics SDK. Step data is not transmitted to the developer. Nothing is written to HealthKit.

Deleting data

Deleting the app removes local saves and the weather cache. Step records in Health remain: the system keeps them, not the game. Step and location access can be revoked in iOS Settings, under Health and under Privacy & Security. Resetting history inside the game clears story progress stored on the device.

Children

The game does not offer registration and does not collect a name or contact details through its interface.
