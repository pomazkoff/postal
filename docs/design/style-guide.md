## 2. Стиль
- Матовый пластилин в духе The Neverhood: отпечатки пальцев, вмятины, грубая лепка, кривизна, низкая детализация. Персонаж — чисто пластилин, без ткани/тряпичности.
- Мир пустой и меланхоличный: людей нет. Сюрреал «безумный», но тихий.
- Насыщенная палитра: охра, бирюза, кирпич, горчица, тил-тени; тёплый студийный свет + цветные акцентные подсветки (тёплый оранжевый и бирюзовый glow).
- Микс: **V2 — база** (раскладка слоями, тил-небо, земля-разрез, постройки V2) + **сюрреальные элементы V3** отдельными слоями. V3 как цельный кадр (`v2/phone_V3_deranged.jpg`) — не база.

## 4. Мир и камера
- Одна горизонтальная лента, строгий вид сбоку (ортографически, камера ровно на уровне), вертикальный телефон. Движение героя слева направо, профиль вправо.
- Кадр 1170×2532: линия дороги `GY=1720` (~68% высоты); сверху небо+дальние планы, снизу разрез земли с находками; внизу узкая полоса сумки («сумка уже, мира больше»).
- Слои и параллакс (коэффициенты из compose.py): небо (градиент тила) → дальний Н 0.1 → средний С 0.4 (затемнён 0.75–0.85) → основной О 1.0 (постройки, герой, дорога) → разрез П 1.0 → передний Ф 1.3 (редкий, размыт, полупрозрачный). Переход дальнего плана в небо — альфа-рампа сверху.
- **ОТКРЫТО:** в phone_bc нет переднего плана — его вид в новой палитре не утверждён; шейдер «сырой пластилин впереди» не сделан; время суток.

## 5. Почтальон
- Образ: вариант 02 — высокий, худой, сутулый, вытянутое «носатое» лицо, кепка, шарф, сумка с письмами на груди, посох из телеграфного столба с изоляторами. Игровой вид — side_seed33.
- **РЕШЕНО (2026-11-04, Илья):** глаза — тёмные пустые глазницы без зрачков, как у seed33; не пуговицы.
- Читаемость (утверждено, вариант (b)+(c)):
  1. тёмный контур: дилатация альфы 4 px, `#1C100A` α 210, blur 1;
  2. тёплый рим-свет на краях сверху-слева (свет сзади-сверху): 55% цвета + 50% от (255,200,120);
  3. успокоение фона вокруг героя — **эффект движка, следует за ним**: blur 6, насыщенность ×0.45, яркость ×0.8, эллипс-маска (поля ±170 px по бокам, −150 сверху, +60 снизу), растушёвка 90, сила 200/255;
  4. шарф ржаво-красный `#CD3C23`.
- Масштаб: высота героя **430 px из 2532** (~17% высоты экрана, ~37% ширины 1170); стопы на линии дороги (`GY−PH+30`). Постройки основного плана 1250–1500 px (≈3–3.5 роста героя), «ящик выше деревьев» ~1500 px. Масштаб героя фиксирован.

## 6. Анимация
Перекладка (cut-out rig): части head, torso, arm_upper, arm_lower, thigh, shin, foot, staff; дальние конечности затемнены ×0.62. Цикл 8 кадров (`01_contact_R … 08_up_L`), **12 fps**, jitter торса+головы ±1 px на кадр (1–2 px «под глину»), голова жёсткая ±0.5°. Посох упирается в землю. **ОТКРЫТО:** анимации кроме ходьбы, эмоции в игре (есть только `v03/expr_*`).

## 8. Генерация (что сработало)
- Модель: `fal-ai/flux-pro/kontext/max`, `image_url` = `postman_fal/v03/side_seed33.jpg` (стиль-референс), `seed` 3 (и 9 для кадров), `safety_tolerance` "5", jpeg. Вырезка фона: `fal-ai/birefnet`.
- Не использовать: `flux-pro/v1.1-ultra` (реалистичные миниатюры), flux-lora Neverhood (грубо).

Шаблон для одиночного объекта (V3 `gen.py`):
```
Remove the character completely. Make ONLY the single object described below, nothing else, no houses, no buildings, no scenery, sculpted from the same matte handmade plasticine clay with fingerprints and crude lumpy sculpting as this image, The Neverhood style, rich saturated clay colors, warm studio light. <ОБЪЕКТ с цветами из палитры>. Strict flat side view, no base, no ground, isolated on a plain flat light beige background.
```
Шаблон для сцены/фона/полосы земли (V2 `gen.py`):
```
Remove the character completely and build a new scene from the same matte handmade plasticine clay with fingerprints and crude lumpy sculpting as this image, The Neverhood style, surreal whimsical deranged architecture. Rich saturated clay palette: ochre, turquoise, brick red, mustard, deep teal shadows; warm studio light with colored accent lights. Deserted, melancholic, no people. Strict orthographic side view like a 2D side-scrolling game, camera exactly level, flat theatre-stage layers, nothing seen from above. <ОПИСАНИЕ>
```
Для полос: «uniform from the left edge to the right edge», 21:9. Для построек 3:4 / 9:16 + «Standing directly on the bottom edge, no base, plain flat beige background».
Герой (новые ракурсы): kontext max от `02_flux_ultra_34.jpg` + суффикс KEEP из `postman_fal/v03/gen.py`.
